PROGRAM 3: KELILING PERSEGI

Sama seperti Program 2, tapi sekarang menghitung keliling! 🔄

🌟 Apa Itu Program Ini?

Program ini menanyakan panjang sisi, lalu menghitung keliling persegi dengan rumus Keliling = 4 × sisi. Pola programnya hampir sama dengan Program 2 — bedanya cuma rumusnya!

💻 Kode Program

🐍 Python sisi = int(input("Masukkan panjang sisi : "))
keliling = 4 * sisi
print("Keliling persegi : ", keliling)
⬇️ Unduh hitung_keliling.py

🔍 Penjelasan Baris per Baris

  • sisi = int(input("...")) — sama seperti Program 2: minta input, ubah jadi angka, simpan di variabel sisi.
  • keliling = 4 * sisi — persegi punya 4 sisi yang sama panjang, jadi keliling = 4 dikali sisi. Angka 4 di sini disebut konstanta (nilai tetap).
  • print("Keliling persegi : ", keliling) — tampilkan hasilnya.

💡 Pola yang sama! Perhatikan: Program 2 dan 3 itu pola yang sama — input → proses → output. Hanya rumusnya yang beda. Inilah pengenalan pola dalam berpikir komputasional!
