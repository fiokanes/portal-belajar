Apa Itu Algoritma? ⌨️

Algoritma adalah langkah-langkah berurutan dan logis untuk menyelesaikan suatu masalah. Algoritma yang baik harus jelas, urut, dan bisa dijalankan siapa pun (termasuk komputer!).

📋 Ciri-Ciri Algoritma yang Baik

✅

Jelas & Tepat

Setiap langkah tidak membingungkan dan tidak bermakna ganda.

🔢

Ada Input & Output

Menerima masukan dan menghasilkan keluaran yang diharapkan.

🏁

Berakhir (Finite)

Ada langkah berhenti — tidak berputar terus tanpa akhir.

♻️

Efektif

Langkah-langkahnya bisa dikerjakan dan tidak membuang waktu.

🛠️ Cara Menulis Algoritma

1. Bahasa Natural (Kalimat Biasa)

  • Mulai
  • Cuci tangan
  • Ambil mie instan dan air
  • Rebus air hingga mendidih
  • Masukkan mie, tunggu 3 menit
  • Tiriskan dan sajikan
  • Selesai

2. Flowchart (Diagram Alir)

Menggunakan simbol: oval (mulai/selesai), jajar genjang (input/output), persegi (proses), belah ketupat (keputusan), panah (alur).

📌 Contoh Pseudocode "Cek Bilangan Ganjil/Genap"

INPUT angka → JIKA angka % 2 == 0 MAKA "Genap" SELAINNYA "Ganjil"

3. Struktur Dasar Algoritma

// Urutan (sequence)
INPUT nilai1, nilai2
jumlah = nilai1 + nilai2

// Percabangan (selection)
JIKA jumlah > 100 MAKA tampilkan "Besar"
SELAINNYA tampilkan "Kecil"

// Perulangan (iteration)
ULANGI 3 KALI: tampilkan "Halo!"

Tiga struktur ini (urutan, percabangan, perulangan) adalah fondasi semua program komputer!
