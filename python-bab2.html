PROGRAM 2: LUAS PERSEGI

Program interaktif pertama — bertanya dulu, baru menghitung! 🧮

🌟 Apa Itu Program Ini?

Program ini menanyakan panjang sisi persegi kepadamu, lalu menghitung luasnya dengan rumus Luas = sisi × sisi. Ini pertama kalinya programmu berinteraksi dengan pengguna — bukan hanya mencetak tulisan! 🎉

💻 Kode Program

🐍 Python sisi = int(input("Masukkan panjang sisi : "))
luas = sisi * sisi
print("Luas persegi adalah : ", luas)
⬇️ Unduh bangun_datar.py

🔍 Penjelasan Baris per Baris

  • sisi = int(input("...")) — tiga hal sekaligus: input() menanyakan sesuatu, int() mengubah jawaban menjadi angka, lalu hasilnya disimpan ke variabel sisi.
  • luas = sisi * sisi — menghitung luas dengan mengalikan sisi dengan dirinya sendiri, lalu menyimpannya di variabel luas.
  • print("...", luas) — menampilkan teks dan isi variabel luas.

💡 Kenapa pakai int()? Karena input() selalu memberi teks. Kalau tidak diubah jadi angka (int), Python tidak bisa menghitung "5 × 5"!
