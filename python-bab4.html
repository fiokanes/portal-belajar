PROGRAM 4: LUAS PERSEGI PANJANG

Sekarang programnya butuh DUA input sekaligus! 🧮✨

🌟 Apa Itu Program Ini?

Program ini menanyakan panjang dan lebar, lalu menghitung luasnya dengan rumus Luas = panjang × lebar. Bedanya dari program sebelumnya: sekarang ada dua variabel input yang bekerja sama! 🤝

💻 Kode Program

🐍 Python panjang = int(input("Masukkan panjang : "))
lebar = int(input("Masukkan lebar : "))
luas = panjang * lebar
print("Luas : ", luas)
⬇️ Unduh hitung_luas_persegi_panjang.py

🔍 Penjelasan Baris per Baris

  • panjang = int(input("Masukkan panjang : ")) — input pertama disimpan di variabel panjang.
  • lebar = int(input("Masukkan lebar : ")) — input kedua disimpan di variabel lebar. Dua variabel berbeda!
  • luas = panjang * lebar — kalikan kedua variabel. Perhatikan: program jalan berurutan dari atas ke bawah (disebut eksekusi sekuensial).
  • print("Luas : ", luas) — tampilkan hasilnya.

💡 Variabel itu seperti kotak penyimpanan! panjang dan lebar adalah dua kotak berbeda yang masing-masing menyimpan satu angka.
