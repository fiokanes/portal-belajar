Program pertamamu dalam dunia coding! 🚀

🌟 Apa Itu Program Ini?

Semua programmer di dunia memulai dari sini! Hello World adalah program paling sederhana yang mencetak tulisan "Hello World" di layar. Ini cara Python menyapa dunia — dan cara kamu kenalan dengan bahasa pemrograman. 🤝

💻 Kode Program

🐍 Python print("Hello World")
⬇️ Unduh main.py

🔍 Penjelasan Baris per Baris

  • print( ... ) — fungsi bawaan Python untuk mencetak atau menampilkan sesuatu ke layar.
  • "Hello World" — teks (disebut string) yang ingin ditampilkan. Diapit tanda kutip " ".

💡 Tahukah kamu? Tanda kutip itu penting! Kalau kamu lupa, Python akan bingung dan bilang SyntaxError.
