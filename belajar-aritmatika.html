😎 Apa Sih Bilangan Bulat Itu?

Hey guys! bilangan bulat adalah kumpulan angka yang sering kita temuin sehari-hari.

🎯 Tiga Jenis Bilangan Bulat:

  • Bilangan Positif (+): 1, 2, 3, 4, 5, ... 😄
  • Bilangan Negatif (-): -1, -2, -3, -4, -5, ... 🌡️
  • Nol (0): Bukan positif, bukan negatif 😂

... -4, -3, -2, -1, 0, +1, +2, +3, +4 ...

➕ Penjumlahan Bilangan Bulat

1️⃣ Tanda Sama = Jumlahkan

  • (+3) + (+5) = +8
  • (-4) + (-6) = -10

2️⃣ Tanda Beda = Adu Kuat 💪

  • (+7) + (-3) = +4 (7 lebih besar!)
  • (-9) + (+5) = -4 (9 lebih besar!)

➖ Pengurangan Bilangan Bulat

🔑 Trik Rahasia:

a - b = a + (-b)

Balik tanda belakang, terus tambahin!

  • (+8) - (+3) = (+8) + (-3) = +5
  • (+6) - (-4) = (+6) + (+4) = +10 🎉

⚠️ Ingat!

Minus × Minus = Plus! Jangan sampai kebalik ya!

✖️ Perkalian Bilangan Bulat

📋 Aturan Tanda:

  • (+) × (+) = (+) ✅ Positif
  • (-) × (-) = (+) ✅ Positif (ajaib!)
  • (+) × (-) = (-) ❌ Negatif
  • (-) × (+) = (-) ❌ Negatif

💡 Trik:

"Tanda SAMA = POSITIF, tanda BEDA = NEGATIF"

➗ Pembagian Bilangan Bulat

Aturan tandanya sama kayak perkalian!

  • (+12) ÷ (+3) = +4
  • (-20) ÷ (-5) = +4 ✅
  • (+18) ÷ (-6) = -3 ❌

📌 Apa Itu Bilangan Bulat?

Bilangan bulat adalah kumpulan angka yang terdiri dari bilangan positif, negatif, dan nol. Ditulis: ..., -3, -2, -1, 0, 1, 2, 3, ...

➕ Penjumlahan

  • ✅ Tanda sama: jumlahkan angkanya, tanda tetap
  • ✅ Tanda beda: kurangkan angkanya, ikut tanda yang lebih besar
  • ✅ Contoh: (+5) + (+3) = +8, (-5) + (-3) = -8

➖ Pengurangan

  • 🔑 Trik: a - b = a + (-b)
  • 🔑 Balik tanda angka belakang, lalu tambahkan
  • 🔑 Contoh: 7 - 3 = 7 + (-3) = 4

✖️ Perkalian & ➗ Pembagian

  • ✅ Tanda sama = Positif: (+) × (+) = (+), (-) × (-) = (+)
  • ❌ Tanda beda = Negatif: (+) × (-) = (-), (-) × (+) = (-)
  • 💡 Aturan perkalian dan pembagian SAMA

💡 Rumus Singkat

a + (-b) = a - b
Penjumlahan negatif
a - (-b) = a + b
Kurang negatif
(-a) × (-b) = +ab
