🔢 BAB 1: POLA BILANGAN

Pelajari barisan bilangan, pola aritmetika dan geometri! 📊✨

Apa Itu Pola Bilangan? 🔢

Pola bilangan adalah susunan bilangan yang mengikuti aturan tertentu. Dengan memahami pola, kita dapat menentukan bilangan berikutnya atau rumus umumnya.

📊 Jenis-jenis Barisan Bilangan

➕

Barisan Aritmetika

Barisan dengan beda (selisih) tetap antar suku. Contoh: 2, 5, 8, 11, 14, ... (beda = 3)

✖️

Barisan Geometri

Barisan dengan rasio (pembagian) tetap antar suku. Contoh: 3, 6, 12, 24, ... (rasio = 2)

📐 Rumus Suku ke-n Barisan Aritmetika

Un = a + (n-1)b

Dimana: a = suku pertama, b = beda, n = nomor suku

📐 Rumus Suku ke-n Barisan Geometri

Un = a × r^(n-1)

Dimana: a = suku pertama, r = rasio, n = nomor suku

📐 Rumus Jumlah n Suku Pertama Barisan Aritmetika

Sn = n/2 × (2a + (n-1)b)

Atau: Sn = n/2 × (a + Un)
