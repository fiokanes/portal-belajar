👋 Apa Itu Python?

Python adalah bahasa pemrograman yang mudah dibaca seperti bahasa Inggris biasa. Cocok banget buat pemula! Dengan Python kamu bisa membuat program sendiri — mulai dari yang sederhana sampai yang keren.

🛠️ Cara Menjalankan Program

  1. Unduh Python di python.org dan install di komputermu
  2. Klik tombol ⬇️ Unduh Kode di halaman tiap program
  3. Buka file .py dengan IDLE (sudah ikut terinstall)
  4. Tekan F5 untuk menjalankan programnya! 🚀
