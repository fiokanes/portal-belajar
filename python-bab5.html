PROGRAM 5: PROGRAM KASIR

Program paling lengkap — kamu baru saja membuat kasir toko! 🛒

🌟 Apa Itu Program Ini?

Ini program paling seru! Kamu membuat kasir toko "TOKO CERIA" yang bisa menerima 2 barang belanjaan (nama, harga, dan jumlahnya), menghitung subtotal tiap barang, lalu menjumlahkan semuanya jadi total belanja. Semua konsep yang sudah kamu pelajari dipakai di sini! 🎓

💻 Kode Program

🐍 Python print("================================")
print("TOKO CERIA")
print("================================")
barang1 = input("Nama Barang Pertama : ")
harga1 = int(input("Harga Barang Pertama : "))
jumlah1 = int(input("Jumlah Barang Pertama : "))
barang2 = input("Nama Barang Kedua : ")
harga2 = int(input("Harga Barang Kedua : "))
jumlah2 = int(input("Jumlah Barang Kedua : "))
total1 = harga1 * jumlah1
total2 = harga2 * jumlah2
total_belanja = total1 + total2
print("\\n================================")
print(barang1, ":", total1)
print(barang2, ":", total2)
print("================================")
print("Total Belanja : ", total_belanja)
print("================================")
print("Terima kasih telah berbelanja!")
⬇️ Unduh program_kasir.py

🔍 Penjelasan Bagian per Bagian

1. Buka toko 🏪

Tiga print() pertama membuat papan nama toko — lengkap dengan garis ==== sebagai bingkai.

2. Terima pesanan 📝

Enam input() menyimpan data barang: barang1/2 (teks, tanpa int() karena nama bukan angka) dan harga1/2, jumlah1/2 (angka, pakai int()).

3. Hitung struk 🧮

  • total1 = harga1 * jumlah1 — subtotal barang pertama (harga × jumlah).
  • total2 = harga2 * jumlah2 — subtotal barang kedua.
  • total_belanja = total1 + total2 — jumlahkan semuanya!

4. Cetak struk 🧾

Program menampilkan struk lengkap: nama barang, subtotalnya, dan total belanja. Perhatikan \\n di dalam string — itu kode untuk baris baru (enter)!

💡 Konsep penting: ada 6 variabel yang bekerja sama di sini. Kamu sudah membuat program yang terstruktur — ini awal dari pembuatan aplikasi sungguhan!
